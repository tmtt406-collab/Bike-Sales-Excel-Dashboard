# Bike Sales Excel Dashboard

## About the Project

This project looks at customer data to understand what factors may be related to bike purchases.

I used **Microsoft Excel** to clean the data, create PivotTables and charts, and build a dashboard to make the results easier to understand.

## Dataset

The original dataset had **1,026 records**. After removing duplicates, I worked with **1,000 customer records**.

The data includes information such as:

- Age
- Gender
- Income
- Occupation
- Commute distance
- Region
- Bike purchase status

## What I Did

- Removed duplicate records
- Cleaned and standardized some category values
- Created age groups using an Excel `IF` formula
- Used PivotTables to compare customer groups
- Created PivotCharts and an Excel dashboard
- Looked for patterns in customer purchasing behavior

## Main Findings

- Customers aged **31–54** had a higher bike purchase rate than the other age groups.
- Customers with a **2–5 mile commute** had the highest purchase rate, at about **58.6%**.
- The **Pacific region** had the highest purchase rate, at about **58.9%**.
- Customers who purchased bikes had a slightly higher average income than customers who did not.
- Bike purchase rates were fairly similar between male and female customers.

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- IF formulas
- Data cleaning
- Data visualization
- Dashboard creation

## Project Process

**Raw Data → Data Cleaning → PivotTable Analysis → Dashboard → Insights**
